Part 01 • Lecture Foundations

What is a Causal Loop Diagram (CLD)?

A visual language for mapping system architecture. CLDs illuminate how interconnected variables generate systemic behaviors through feedback rather than linear cause-and-effect.

Polarity (+) Polarity (−)

Static Exemplar Map: Reusable Cup Adoption

3-Variable Closed Feedback Loop
Loop Interpretation: Higher cup adoption reduces visible waste, reinforcing green social norms, driving further cup adoption. (+) × (+) × (+) = (+)
1

Variables (System States)

Quantities, conditions, or feelings that fluctuate over time (e.g., Usage, Cost, Trust). Must be quantifiable or directionally variable.

2

Positive Link Polarity (+)

Indicates change in the same direction. If Variable X increases, Variable Y increases above baseline. If X decreases, Y decreases.

3

Negative Link Polarity (−)

Indicates change in the opposite direction. If Variable X increases, Variable Y decreases below baseline, creating counter-forces.

4

Closed Feedback Loops

When causal chains wrap back onto themselves, creating non-linear dynamic behavior: either self-reinforcing exponential growth/decay or goal-seeking stability.

Part 02 • Loop Classification Engine

Polarity Rules & Mathematical Loop Logic

To determine whether a feedback loop amplifies change (Reinforcing) or balances change (Balancing), count the total number of negative (−) causal links in the closed loop.

RULE 01 Even Count of (−) Links

Reinforcing Feedback Loop (R)

0, 2, 4, or any EVEN number of negative links yields a net positive sign product. The loop amplifies disturbances, driving exponential virtuous growth or vicious collapse.

RULE 02 Odd Count of (−) Links

Balancing Feedback Loop (B)

1, 3, 5, or any ODD number of negative links yields a net negative sign product. The loop counteracts disturbances, seeking stability, capacity limits, or equilibrium.

Part 03 • Self-Amplifying Dynamics

Reinforcing Loops (R): Growth & Collapse Engines

Reinforcing feedback dynamics create compounding effects over time. A initial shift in any variable spirals continuously in the same direction, generating virtuous adoption cycles or vicious decay traps.

Part 04 • Stabilizing Feedback Dynamics

Balancing Loops (B): Goal-Seeking System Limits

Balancing loops counteract changes, driving the system toward a target state or capacity ceiling. They act as natural brakes or regulators, preventing unbounded exponential runaway.

Part 05 • AI-Assisted Educational Engineering

Vibe Coding & Interactive Dashboard Engineering

"Vibe Coding" is the practice of leveraging structured domain architecture and natural-language AI prompts to build robust, single-file interactive simulations and educational tools without manual boilerplate.

1 Prompt Architecture

Define clear system boundaries: layout design tokens (e.g. dark slate palette), interactive state models, strict mathematical polarity formulas, and single-file mandate.

2 Iterative Generation

Direct the LLM to output clean, modular code with inline Tailwind styling, dynamic SVG arrow geometries, and stateful JavaScript simulators in a consolidated file.

3 Human-in-the-Loop Audit

Inspect SVG line clearances (stopping arrows 15-20px outside node containers), verify math formula engine edge cases, and test responsive layouts.
